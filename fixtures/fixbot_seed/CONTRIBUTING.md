# Правила для разработчиков и их ИИ-агентов

1. Работайте в своей ветке `feature/<имя>-<задача>` и открывайте PR в `feature/lab-main`.
2. Код — в `shop/`, тесты своей фичи — в `tests/` (`unittest`, без сторонних пакетов). Новая фича без тестов не принимается.
3. Перед push подтяните свою ветку (`git pull`). После коммита итогового агента в вашей ветке force push запрещён.
4. Не удаляйте и не меняйте чужие тесты: это решает только человек.
5. Итоговый агент сам совмещает ваш PR с общей веткой (Mergiraf, затем модель), проверяет тесты всех фич и вливает. Если он пишет «Нужен человек» — прочитайте комментарий в PR.

Локально: `git config merge.mergiraf.name mergiraf` и
`git config merge.mergiraf.driver "mergiraf merge --git %O %A %B -s %S -x %X -y %Y -p %P -l %L"`;
`.gitattributes` уже включает Mergiraf для `*.py`.
